# РОК-Н-РОЛЛ ГОНКИ

Браузерный оммаж аркадным гонкам: одна HTML-страница, canvas, локальное сохранение прогресса. В каждой гонке три невыбранных гонщика выходят боссами на фирменных машинах, плюс двое случайных ИИ. HUD на трассе — кокпит, место, компактные лидеры и миникарта без лишних панелей.

## Структура

- `rnr.html` — игра (выбор гонщика и машин-карусель → гараж → тренажёрка)
- `Editor.html` — лаборатория: кузов, колёса, слои, характеристики и свои машины
- `editor.bat` — открыть лабораторию
- `editor/` — скрипты и стили лаборатории
- `index.html` — вход для GitHub Pages (переход к игре)
- `music.js` — URL треков (меню / выбор машины / гараж / интро / гонка)
- `sounds.js` — эффекты (`money` / `buy` / `tune`): локальные `assets/sounds/FX/`, запасной URL на ikrinka
- `assets/machines/cars/` — кузова `01`–`10` и слои брони `NN_armor_1` … `NN_armor_6` (`.webp`, иначе `.png`). Личные: Медведь `01`, Ерш `08`, Бегемотик `09`, Башкир `07`. Магазин: «Жеребец» `10` (миниган, прыжок, ульта «Табун»). Хитбокс в гонке — прямоугольник спрайта кузова (как рамка в лаборатории), не SVG.
- `assets/image/avatars/` — портреты `NN_Player` и рост `NN_Player_fullbody` (`.webp`, иначе `.png`)
- `assets/image/comics/Bear/` — кадры интро Медведя (`1.png` … `7.png`)
- `assets/image/comics/Ersh/` — кадры интро Ерша (`1.png` … `6.png`)
- `assets/image/comics/Begemotik/` — кадры интро Бегемотика (`1.png` … `6.png`)
- `assets/image/comics/Bashkir/` — кадры интро Башкира (`1.png` … `7.png`)
- `assets/image/textures/map/` — тайлы фона карт по биомам: папка имени биома, кадры `01.webp`, `02.webp`, … подряд (дыры в нумерации обрывают цепочку; нет файлов — процедурный грунт)

## Запуск

Откройте `rnr.html` в браузере, дважды щёлкните `start.bat` или запустите локальный сервер из корня проекта.

В гонке: WASD или стрелки — руль; **Z / P** — оружие; **X / {** — нитро или прыжок (зависит от машины); **C / }** — ульта; ESC — пауза. Клавиши можно сменить в настройках.

Для настройки машин дважды щёлкните `editor.bat` или откройте `Editor.html`. На холсте: колесо мыши — зум, средняя кнопка — панорама, «В кадр» вписывает машину целиком. Блок **Слои**: галочка скрывает слой, ↑↓ меняют порядок (верхний рисуется поверх). Сохраните настройки — игра на этом же адресе подхватит колёса, кузов, броню, нитро, порядок слоёв, характеристики и добавленные машины. Кнопка **Полигон** выезжает текущую машину на тестовый овал (3 круга, без соперников и без записи карьеры). ESC или пункт паузы «В лабораторию» возвращает в редактор. JSON можно скачать и загрузить обратно. Из гаража лаборатория открывается клавишей E.

Музыка: ссылки на MP3 задаются только в `music.js` (категории `main`, `change`, `garage`, `intro`, `racing`). Интро гонщиков — `intro[0]`…`intro[3]` (Медведь, Ерш, Бегемотик, Башкир). Звуки: `sounds.js` (`money` — деньги на трассе, `buy` — покупка, `tune` — тюнинг); на сайте играются файлы из `assets/sounds/FX/`. Голоса имён на выборе гонщика — массив `VOICE_TRACKS`. Сначала экран загрузки с прогрессбаром (картинки, шрифты, трек меню); если дольше 8 секунд — совет отключить VPN. Затем стартовый экран; любая клавиша, клик или кнопка геймпада открывает меню и включает звук.

Читы: на главном экране пункт **ЧИТЫ**, код `deliane` — режим разработчика: деньги, все машины (включая чужие личные), выбор гонщика сразу после кода. В dev на главной и в паузе появляется **Выбор трассы**.

## Сборка

Сборка не нужна: статический HTML и SVG.

## Деплой

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт на **GitHub Pages**. Сборка не требуется: в артефакт уходит корень репозитория.

После публикации игра доступна по адресу:

https://divangames.github.io/racing/

## Технологии

- HTML5 Canvas
- JavaScript (без фреймворков)
- SVG-ассеты
- GitHub Pages
