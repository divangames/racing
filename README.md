# РОК-Н-РОЛЛ ГОНКИ

Браузерный оммаж аркадным гонкам: одна HTML-страница, canvas, локальное сохранение прогресса. В автопарке 21 стоковый кузов. В карусели сначала магазин по возрастанию цены (хлам, затем средний класс, затем V8 и выше), затем личные машины гонщиков. В заезде игрок, босс Борис Бык и три случайных ИИ. В дивизионах 1–2 ИИ едут только на стартовом хламе; в 3–4 — хлам и средний класс, не на V8 и выше. HUD на трассе — кокпит, место, компактные лидеры и миникарта без лишних панелей.

Карьера рассчитана на долгую прокачку: пять стартовых кузовов открыты сразу (200–400$). Касса старта 1000$ — после любой покупки хлама остаётся на первый слот гаража (амортизаторы 550$ / шины 600$). Средний класс (Такси / Пикап / Купе / Фургон / Скорая, 1400–3000$) открывается с 3–5 этапа. Первое «настоящее» магазинное авто (V8) открывается с 6-го этапа и стоит несколько сезонов призов. Боссы в первом дивизионе едут на стоке хлама; их броня и скилы догоняют игрока только к поздним дивизионам. Перед гонкой можно поставить сумму с кассы на себя или на соперника — кэфы 1/2/3 места считаются на старте; без денег на сумму ставка не выбирается. После финиша — подиум, затем экран «что дальше»: приз 1–3, бонус за серию побед, почему открылся кузов, реванш на этой трассе; после пяти побед — выбор уже проеханной. Реванш не двигает календарь этапа.

## Структура

- `rnr.html` — игра (гонщик → машины → гараж / тренажёрка / оружейка). Кнопка «Полигон» в лаборатории открывает простую проверочную трассу (`?lab=1`), её нет в карьере.
- `world-intro.js` — пролог из семи кадров после «нажмите любую кнопку»; текст и арт в `assets/data/cats/00`, музыка `assets/music/Load`.
- `career.js` — после гонки: новости карьеры, серия, разблокировки, реванш.
- `notice.js` — одноразовое окно на титуле: скоро клиент вместо вкладки, автодополнения, онлайн.
- `vfx/` — слой частиц [three.quarks](https://github.com/Alchemist0823/three.quarks) поверх canvas: взрывы, пыль, выстрелы, дым и огонь с подбитого корпуса (`quarks-wreck.js`), дождь / снег / песчаная буря / извержение на вулкане (`quarks-weather.js`). Молния и дымка — холст (`weather-fx.js`), капель на камере нет. Из-под колёс — снег на льду и брызги по лужам. Three.js грузится с CDN. Если WebGL или CDN недоступны, осадки остаются на холсте. Откат: `restore-quarks-rollback.bat` (`rollback/pre-quarks/`).
- `combat-kits.js` — уникальные оружие и ульты стоковых кузовов (стрельба, ульта, таран, купол).
- `starter-kits.js` — пять стартовых кузовов 12–16, киты хлама и сдача кассы в два слота тюнинга.
- `mid-kits.js` — пять кузовов среднего класса 17–21 и пул ИИ дивизионов 3–4.
- `armory.js` — оружейка в хабе: прокачка ствола и ульты выбранной машины.
- `chars.js` — список гонщиков (`CHARS`): игра и лаборатория читают один файл. Новый персонаж — папка `assets/data/players/NN/` (портрет, рост, `comics/`, `voice/`, сюжет).
- `voice.js` — банк реплик (`lines.json`), выноска у аватара в списке мест.
- `Editor.html` — лаборатория: машины и вкладка **Карта**. Свободный режим, старт/финиш, браузер контента всегда внизу (паки, итемы, превью), сплайн, покрытие. Ctrl+S пишет JSON.
- `start.bat` / `editor.bat` — игра и лаборатория через `http://127.0.0.1:8765/` (общий localStorage)
- `local-server.bat` — проверяет HTTP на порту 8765 и при необходимости поднимает `tools/rnr-http.py`
- `editor/` — скрипты и стили лаборатории; Montserrat лежит в `assets/fonts/montserrat/`
- `tracks.js` — деколи, итемы, погода, загрузка своих трасс.
- `assets/object/` — паки ассетов: папка `<id>.labr` (`pack.labr` + `*.oblab` + PNG/WebP/GIF). POST `/__save-pack`, `/__save-oblab`, GET `/__object-packs`.
- `assets/data/tracks/` — JSON петель (`index.json` + `id.json`). Текстуры: `Textures/biomes/`, `Textures/road/`, `Textures/objects/` (POST `/__save-texture`).
- `tools/rnr-http.py` — HTTP на порту 8765: запись машин, трасс, текстур и ассетов
- `tools/rnr-ensure-http.py` — живой GET `/rnr.html`; мёртвый python на порту снимается и сервер стартует заново
- `index.html` — презентация: скачать клиент, сюжет, гонщики, скрины заезда, роадмап
- `music.js` — сам читает `assets/music/{main,change,garage,intro,racing}/`. Сколько MP3 в папке, столько треков; меню/гараж/гонка играют случайно. Интро — `01.mp3`… по номеру гонщика. Подпапка `old` не берётся.
- `sounds.js` — эффекты (`money` / `buy` / `tune`) из `assets/sounds/FX/` (те же имена: `money.mp3`, `CashBay.mp3`, `carPay.wav`). Если файла нет — тот же путь с `ikrinka24.com`.
- `car-audio-voice.js` / `car-audio.js` — двигатель игрока и соперников: `sound_001.wav` … `_005.wav`, чужие тише с расстоянием и панорамой слева/справа.
- `assets/data/cars/NN/` — слот машины: `car.json`, кузов `NN.webp` (иначе `.png`), контур `NN_col.svg`, броня в `armor/`, повреждения в `damage/` (пока у `01`), звук двигателя в `sound/sound_001.wav` … `_005.wav`. Нет папки `sound` — лупы из `assets/sounds/engine/`. Номера папок — слоты ассетов, не порядок в меню. Стартовый хлам: `12` Тазик, `13` Каблук, `14` Жезл, `15` Козёл, `16` Борт. Средний класс: `17` Такси, `18` Пикап, `19` Купе, `20` Фургон, `21` Скорая. В карусели сначала магазин по цене, затем личные: Медведь `01`, Ерш `08`, Бегемотик `09`, Башкир `07`, Янот `11` («Бричка»). Новая машина без `owner` встаёт в магазин по цене. Хитбокс в гонке — прямоугольник спрайта кузова (как рамка в лаборатории), не SVG. Тень — силуэт по альфе кузова без брони.
- `assets/data/players/NN/` — портрет `NN_Player`, рост `NN_Player_fullbody`, кадры интро в `comics/`, сюжет в `NN_Имя.md`, реплики и MP3 в `voice/` (лист `VOICE.md`; ведущий — `host/voice/`). НПС сетки — `07`–`12`.
- `assets/machines/wheels/` — спрайт колеса `wheel-strip.webp` (8 кадров); запасные `.png` / `.svg`

## Запуск

Откройте `rnr.html` в браузере, дважды щёлкните `start.bat` или запустите локальный сервер из корня проекта.

`start.bat` и `editor.bat` открывают страницы с **одного адреса** `http://127.0.0.1:8765/` (нужен Python и `tools/rnr-http.py`). Так лаборатория и игра делят настройки машин и могут писать `assets/data/cars/NN/car.json`. Скрипт не смотрит только на занятый порт: если Python слушает 8765, но страницу не отдаёт (зависший процесс), его снимают и поднимают сервер заново. Чужой не-Python на 8765 нужно закрыть вручную. Если сервер так и не поднялся — откроется файл; в этом режиме браузер часто держит отдельное хранилище.

В гонке: WASD или стрелки — руль; **Пробел** — ручник; **Z / P** — оружие; **X / {** — нитро или прыжок (зависит от машины); **C / }** — ульта; ESC — пауза. Клавиши меняются в **Настройка игры → Настройки управления**. Камера (дальше / ближе) — в **Настройка графики**, диапазон 1.75–2.2. Новая игра сначала показывает живой заезд, чтобы подогнать зум; позже его можно сменить в тех же настройках. Машины катятся по инерции, входят в поворот не рывком (прокачка «Поворот» острит руль), в заносе держат шины и управление, с трамплина садятся с пылью и сжатием подвески.

Для настройки машин дважды щёлкните `editor.bat`. Слои в панели перетаскиваются мышью за точечный грип (как в Figma): верх списка — поверх картинки. **Личность авто** задаёт хозяина (или магазин). **Клон** / Ctrl+D добавляет новый слой рядом. **Ctrl+S** сохраняет настройки (окно покажет, вышло или нет). **Копировать размер** / **Вставить размер** переносят ширину и высоту на другой слой того же типа (колесо или нитро). Shift на холсте — движение строго по горизонтали или вертикали. Ctrl+колёсико — размер по Y, Alt+колёсико — по X. «Сохранить настройки» фиксирует слот как базу; «Сбросить к базовым» возвращает его, текущее уходит в бэкап. Правки пишутся в браузер и в `car.json`. Игра рисует машину по тому же стеку.

Музыка: файлы в `assets/music/` (`main`, `change`, `garage`, `intro`, `racing`, `Load`) лежат в репозитории и на Pages. Сколько MP3 в папке — столько треков; меню/гараж/гонка играют случайно. Интро гонщиков — `intro/01.mp3`… по номеру. Если локального клипа нет — запасной путь на **ikrinka24.com**. Звуки: `sounds.js` (`money` / `buy` / `tune`) из `assets/sounds/FX/` с теми же именами; если клипа нет — запасной URL на ikrinka. На выборе гонщика играет случайный дубль `name_01`…`name_03` из `assets/data/players/NN/voice/` (тексты в `lines.json`, событие «Выбор гонщика»), на карточке — выноска с той же фразой. Пустой MP3 пропускается. Сначала экран «нажмите любую кнопку»; после жеста качаются гонщики, комиксы, кузова, броня, тайлы карты, SFX и все треки из `music.js`. Титульный экран открывается только когда очередь закончена. Если дольше 12 секунд — подсказка про VPN; меню само не выскакивает.

Читы: на главном экране пункт **ЧИТЫ**, код `deliane` — режим разработчика: деньги, все машины (включая чужие личные), выбор гонщика сразу после кода. В dev на главной — **Выбор трассы** и **Лаборатория** (перед входом окно: можно испортить машину; Нет / Да). В паузе тоже есть **Выбор трассы**. В гараже клавиша E открывает то же предупреждение.

## Десктоп-клиент

Устанавливаемая игра (не браузер) собирается отдельно в `Full Games`, чтобы не сломать эту папку. Запуск: `Full Games/Запуск.bat`. Подробности — в `Full Games/README.md`.

## Сборка

Сборка браузерной версии не нужна: статический HTML и SVG. Установщик Windows — `Full Games/Собрать-установщик.bat`.

## Деплой

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт на **GitHub Pages**. Сборка не требуется: в артефакт уходит корень репозитория.

После публикации сайт и игра доступны по адресу:

https://divangames.github.io/racing/

Презентация — корень. Скачать Windows-клиент: [Яндекс Диск](https://disk.yandex.ru/d/BHvSSYPNRSt8cQ).

## Технологии

- HTML5 Canvas
- JavaScript (без фреймворков)
- SVG-ассеты
- GitHub Pages
- Three.js + three.quarks (опциональный слой VFX, средний/высокий уровень частиц)
