# РОК-Н-РОЛЛ ГОНКИ

Браузерный оммаж аркадным гонкам: одна HTML-страница, canvas, локальное сохранение прогресса. В автопарке 11 стоковых кузовов, в том числе стартовая «Бричка». В каждой гонке три невыбранных гонщика выходят боссами на фирменных машинах, плюс двое случайных ИИ. HUD на трассе — кокпит, место, компактные лидеры и миникарта без лишних панелей.

## Структура

- `rnr.html` — игра (выбор гонщика и машин-карусель → гараж → тренажёрка)
- `Editor.html` — лаборатория: кузов, колёса, слои, характеристики и свои машины
- `start.bat` / `editor.bat` — игра и лаборатория через `http://127.0.0.1:8765/` (общий localStorage)
- `local-server.bat` — поднимает Python-сервер на порту 8765, если его ещё нет
- `editor/` — скрипты и стили лаборатории
- `index.html` — вход для GitHub Pages (переход к игре)
- `music.js` — URL треков (меню / выбор машины / гараж / интро / гонка)
- `sounds.js` — эффекты (`money` / `buy` / `tune`): локальные `assets/sounds/FX/`, запасной URL на ikrinka
- `assets/machines/cars/` — кузова `01`–`10` и слои брони `NN_armor_1` … `NN_armor_6` (`.webp`, иначе `.png`). Личные: Медведь `01`, Ерш `08`, Бегемотик `09`, Башкир `07`. Магазин: «Жеребец» `10` (миниган, прыжок, ульта «Табун»). Хитбокс в гонке — прямоугольник спрайта кузова (как рамка в лаборатории), не SVG. Тень — силуэт по альфе кузова без брони.
- `assets/image/avatars/` — портреты `NN_Player` и рост `NN_Player_fullbody` (`.webp`, иначе `.png`)
- `assets/image/comics/Bear/` — кадры интро Медведя (`1.png` … `7.png`)
- `assets/image/comics/Ersh/` — кадры интро Ерша (`1.png` … `6.png`)
- `assets/image/comics/Begemotik/` — кадры интро Бегемотика (`1.png` … `6.png`)
- `assets/image/comics/Bashkir/` — кадры интро Башкира (`1.png` … `7.png`)
- `assets/machines/wheels/` — спрайт колеса `wheel-strip.webp` (8 кадров); запасные `.png` / `.svg`

## Запуск

Откройте `rnr.html` в браузере, дважды щёлкните `start.bat` или запустите локальный сервер из корня проекта.

`start.bat` и `editor.bat` открывают страницы с **одного адреса** `http://127.0.0.1:8765/` (нужен Python). Так лаборатория и игра делят настройки машин. Если открыть HTML как файл, браузер часто держит отдельное хранилище.

В гонке: WASD или стрелки — руль; **Z / P** — оружие; **X / {** — нитро или прыжок (зависит от машины); **C / }** — ульта; ESC — пауза. Клавиши меняются в **Настройка игры → Настройки управления**. Камера (дальше / ближе) — в **Настройка графики**, диапазон 1.75–2.2, рядом крутится демо-заезд.

Для настройки машин дважды щёлкните `editor.bat` или откройте `Editor.html`. На холсте: колесо мыши — зум, средняя кнопка — панорама, клик по пустому снимает слой, «В кадр» вписывает машину целиком. **Отметки** (клавиша H) показывают или прячут точки центров, номера и рамки. **← Назад** / **Вперёд →** (Ctrl+Z / Ctrl+Y) отменяют и повторяют правку. Блок **Слои** сразу под кузовом: галочка скрывает слой, ↑↓ меняют порядок. Галочка **Зеркалить пару по Y** двигает левое и правое колесо одной оси вместе (в том числе ширину и высоту). **Ширина / Высота / Множитель** меняют спрайт колеса; в центре диска — точка оси. Колёса рисуются по стеку слоёв: ниже кузова — в колодцах, выше — поверх. **Клон** / Ctrl+D копирует колесо или трубу нитро — дальше каждый элемент сам по себе. Правки пишутся в браузер сами. Игра подхватывает **тот же пакет**, что лаборатория (`editor/data.js`): колёса, кузов, броню, нитро, слои и характеристики. Кнопка **Полигон** выезжает текущую машину на тестовый овал (3 круга, без соперников и без записи карьеры). ESC или пункт паузы «В лабораторию» возвращает в редактор. JSON можно скачать и загрузить обратно. Из гаража лаборатория открывается клавишей E.

Музыка: ссылки на MP3 задаются только в `music.js` (категории `main`, `change`, `garage`, `intro`, `racing`). Интро гонщиков — `intro[0]`…`intro[3]` (Медведь, Ерш, Бегемотик, Башкир). Звуки: `sounds.js` (`money` — деньги на трассе, `buy` — покупка, `tune` — тюнинг); на сайте играются файлы из `assets/sounds/FX/`. Голоса имён на выборе гонщика — массив `VOICE_TRACKS`. Сначала экран загрузки с прогрессбаром (картинки и шрифты). Если файл не найден — его пропускаем; через 8 секунд игра открывается в любом случае. Затем стартовый экран; любая клавиша, клик или кнопка геймпада открывает меню и включает звук.

Читы: на главном экране пункт **ЧИТЫ**, код `deliane` — режим разработчика: деньги, все машины (включая чужие личные), выбор гонщика сразу после кода. В dev на главной и в паузе появляется **Выбор трассы**.

## Сборка

Сборка не нужна: статический HTML и SVG.

## Деплой

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт на **GitHub Pages**. Сборка не требуется: в артефакт уходит корень репозитория.

После публикации игра доступна по адресу:

https://divangames.github.io/racing/

## Технологии

- HTML5 Canvas
- JavaScript (без фреймворков)
- SVG-ассеты
- GitHub Pages
