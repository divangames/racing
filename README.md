# РОК-Н-РОЛЛ ГОНКИ

Браузерный оммаж аркадным гонкам: одна HTML-страница, canvas, локальное сохранение прогресса. В автопарке 11 стоковых кузовов. В карусели сначала магазин по возрастанию цены, затем личные машины гонщиков. В заезде игрок, босс Борис Бык и три случайных ИИ. HUD на трассе — кокпит, место, компактные лидеры и миникарта без лишних панелей.

Карьера рассчитана на долгую прокачку: первое магазинное авто (V8) открывается с 6-го этапа и стоит несколько сезонов призов, а не две победы. Боссы в первом дивизионе едут на стоке; их броня и скилы догоняют игрока только к поздним дивизионам. Перед гонкой можно поставить сумму с кассы на себя или на соперника — кэфы 1/2/3 места считаются на старте; без денег на сумму ставка не выбирается.

## Структура

- `rnr.html` — игра (выбор гонщика и машин-карусель → гараж → тренажёрка). Кнопка «Полигон» в лаборатории открывает простую проверочную трассу (`?lab=1`), её нет в карьере.
- `chars.js` — список гонщиков (`CHARS`): игра и лаборатория читают один файл. Новый персонаж — папка `assets/data/players/NN/` (портрет, рост, `comics/`, `voice/`, сюжет).
- `voice.js` — банк реплик (`lines.json`), выноска у аватара в списке мест.
- `Editor.html` — лаборатория разработчика: кузов, слои (Ctrl+клик — группа, Shift+клик — диапазон, перетаскивание мышью), колёса. Слой «Броня» — превью уровней I–VI на холсте. Отмена и повтор только у выбранного авто. Личность авто — все гонщики из `chars.js` и новые аватары. Вкладка «Карта» — заготовка.
- `start.bat` / `editor.bat` — игра и лаборатория через `http://127.0.0.1:8765/` (общий localStorage)
- `local-server.bat` — проверяет HTTP на порту 8765 и при необходимости поднимает `tools/rnr-http.py`
- `editor/` — скрипты и стили лаборатории; Montserrat лежит в `assets/fonts/montserrat/`
- `assets/data/cars/01` … `11` — `car.json` рабочего слота, `car.base.json` база для сброса, `car.backup.json` предыдущая база. Лаборатория пишет файлы через локальный сервер; игра читает `car.json`.
- `tools/rnr-http.py` — HTTP на порту 8765 со записью `car.json`
- `tools/rnr-ensure-http.py` — живой GET `/rnr.html`; мёртвый python на порту снимается и сервер стартует заново
- `index.html` — вход для GitHub Pages (переход к игре)
- `music.js` — URL треков (меню / выбор машины / гараж / интро / гонка)
- `sounds.js` — эффекты (`money` / `buy` / `tune`): локальные `assets/sounds/FX/`, запасной URL на ikrinka
- `assets/machines/cars/` — кузова `01`–`11` и слои брони `NN_armor_1` … `NN_armor_6` (`.webp`, иначе `.png`). Номера папок — слоты ассетов, не порядок в меню. В карусели сначала магазин по цене, затем личные: Медведь `01`, Ерш `08`, Бегемотик `09`, Башкир `07`, Янот `11` («Бричка»). Новая машина без `owner` встаёт в магазин по цене. Хитбокс в гонке — прямоугольник спрайта кузова (как рамка в лаборатории), не SVG. Тень — силуэт по альфе кузова без брони.
- `assets/data/players/NN/` — портрет `NN_Player`, рост `NN_Player_fullbody`, кадры интро в `comics/`, сюжет в `NN_Имя.md`, реплики и MP3 в `voice/` (лист `VOICE.md`; ведущий — `host/voice/`)
- `assets/machines/wheels/` — спрайт колеса `wheel-strip.webp` (8 кадров); запасные `.png` / `.svg`

## Запуск

Откройте `rnr.html` в браузере, дважды щёлкните `start.bat` или запустите локальный сервер из корня проекта.

`start.bat` и `editor.bat` открывают страницы с **одного адреса** `http://127.0.0.1:8765/` (нужен Python и `tools/rnr-http.py`). Так лаборатория и игра делят настройки машин и могут писать `assets/data/cars/NN/car.json`. Скрипт не смотрит только на занятый порт: если Python слушает 8765, но страницу не отдаёт (зависший процесс), его снимают и поднимают сервер заново. Чужой не-Python на 8765 нужно закрыть вручную. Если сервер так и не поднялся — откроется файл; в этом режиме браузер часто держит отдельное хранилище.

В гонке: WASD или стрелки — руль; **Пробел** — ручник; **Z / P** — оружие; **X / {** — нитро или прыжок (зависит от машины); **C / }** — ульта; ESC — пауза. Клавиши меняются в **Настройка игры → Настройки управления**. Камера (дальше / ближе) — в **Настройка графики**, диапазон 1.75–2.2. Новая игра сначала показывает живой заезд, чтобы подогнать зум; позже его можно сменить в тех же настройках. Машины катятся по инерции, входят в поворот не рывком (прокачка «Поворот» острит руль), в заносе держат шины и управление, с трамплина садятся с пылью и сжатием подвески.

Для настройки машин дважды щёлкните `editor.bat`. Слои в панели перетаскиваются мышью за точечный грип (как в Figma): верх списка — поверх картинки. **Личность авто** задаёт хозяина (или магазин). **Клон** / Ctrl+D добавляет новый слой рядом. **Ctrl+S** сохраняет настройки (окно покажет, вышло или нет). **Копировать размер** / **Вставить размер** переносят ширину и высоту на другой слой того же типа (колесо или нитро). Shift на холсте — движение строго по горизонтали или вертикали. Ctrl+колёсико — размер по Y, Alt+колёсико — по X. «Сохранить настройки» фиксирует слот как базу; «Сбросить к базовым» возвращает его, текущее уходит в бэкап. Правки пишутся в браузер и в `car.json`. Игра рисует машину по тому же стеку.

Музыка: ссылки на MP3 задаются только в `music.js` (категории `main`, `change`, `garage`, `intro`, `racing`). Интро гонщиков — `intro[0]`…`intro[3]` (Медведь, Ерш, Бегемотик, Башкир). Звуки: `sounds.js` (`money` — деньги на трассе, `buy` — покупка, `tune` — тюнинг); на сайте играются файлы из `assets/sounds/FX/`. На выборе гонщика играет случайный дубль `name_01`…`name_03` из `assets/data/players/NN/voice/` (тексты в `lines.json`, событие «Выбор гонщика»), на карточке — выноска с той же фразой. Пустой MP3 пропускается. Сначала экран «нажмите любую кнопку»; после жеста идёт загрузка с музыкой главного меню (`main`). Если файл не найден — его пропускаем; через 8 секунд меню открывается в любом случае.

Читы: на главном экране пункт **ЧИТЫ**, код `deliane` — режим разработчика: деньги, все машины (включая чужие личные), выбор гонщика сразу после кода. В dev на главной — **Выбор трассы** и **Лаборатория** (перед входом окно: можно испортить машину; Нет / Да). В паузе тоже есть **Выбор трассы**. В гараже клавиша E открывает то же предупреждение.

## Сборка

Сборка не нужна: статический HTML и SVG.

## Деплой

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт на **GitHub Pages**. Сборка не требуется: в артефакт уходит корень репозитория.

После публикации игра доступна по адресу:

https://divangames.github.io/racing/

## Технологии

- HTML5 Canvas
- JavaScript (без фреймворков)
- SVG-ассеты
- GitHub Pages
