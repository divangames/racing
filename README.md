# РОК-Н-РОЛЛ ГОНКИ

Браузерный оммаж аркадным гонкам: одна HTML-страница, canvas, локальное сохранение прогресса.

## Структура

- `rnr.html` — игра
- `index.html` — вход для GitHub Pages (переход к игре)
- `music.js` — URL треков (меню / гараж / гонка)
- `assets/machines/` — SVG-прототипы машин

## Запуск

Откройте `rnr.html` в браузере, дважды щёлкните `start.bat` или запустите локальный сервер из корня проекта.

Музыка: ссылки на MP3 задаются только в `music.js` по категориям `main`, `garage`, `racing`. Первое нажатие клавиши или клик включает звук.

## Сборка

Сборка не нужна: статический HTML и SVG.

## Деплой

После каждого пуша в ветку `main` GitHub Actions автоматически публикует сайт на **GitHub Pages**. Сборка не требуется: в артефакт уходит корень репозитория.

После публикации игра доступна по адресу:

https://divangames.github.io/racing/

## Технологии

- HTML5 Canvas
- JavaScript (без фреймворков)
- SVG-ассеты
- GitHub Pages
