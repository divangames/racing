# Правила проекта

- После каждой задачи обязательно выполнять QA: релевантные автоматические тесты, а для UI — проверку реального интерфейса в Electron, взаимодействий, ошибок консоли и разных размеров окна. После исправлений повторять затронутые проверки. В итоговом ответе сообщать результаты и ограничения; не объявлять непроверенное работающим.
- Для всех изменений и ревью UI/UX в этом проекте всегда применять скилл Emil Kowalski `emil-design-eng`: читать `docs/skills/emil-design-eng/SKILL.md`. Источник: https://github.com/emilkowalski/skills. Следовать принципам доступности, мгновенного отклика, уместной анимации и проверки крайних состояний.
- Основной шрифт интерфейса игры и редактора — Bender из локальных `assets/fonts/bender`. Использовать его в DOM и Canvas, включая подписи, подсказки и титры; не подменять основным Segoe UI или Montserrat.
- QA редактора проводить в отдельном временном профиле и с изолированными обработчиками сохранения, чтобы тесты не меняли пользовательские машины, карты и главы.
