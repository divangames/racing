# Сертификат издателя Divan Games

Windows смотрит не на название папки, а на **подпись Authenticode**. После сборки у exe и MSI в свойствах будет издатель «Divan Games».

## Что лежит здесь

| Файл | В git | Зачем |
| --- | --- | --- |
| `divan-games.cer` | да | Открытая часть. Им её ставят в «доверенные», чтобы свой ПК не ругался. |
| `divan-games.pfx` | нет | Закрытый ключ. Им подписывают сборку. |
| `password.txt` | нет | Пароль от pfx. |

`Собрать-MSI.bat` сам создаёт pfx, если его ещё нет, и подписывает установщик.

## Чтобы Windows на этом компьютере заткнулся

Запусти `Доверить-Divan-Games.bat` (один раз, от имени того же пользователя). Сертификат попадёт в «Доверенные издатели» и «Доверенные корневые».

Чужой ПК после скачивания с сайта всё равно может показать SmartScreen: у самоподписанного сертификата нет репутации Microsoft. Для магазина и сайта без жёлтых щитов нужен **купленный** OV/EV Code Signing (DigiCert, Sectigo и т.п.). Тогда кладёшь их `.pfx` сюда под именем `divan-games.pfx` и пароль в `password.txt` — сборка подхватит.

Не коммить pfx. Это ключ студии.
