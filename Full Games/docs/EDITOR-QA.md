# QA редактора — 3 октября 2026

Правила проекта находятся в `AGENTS.md`. Скилл Emil Kowalski сохранён в `docs/skills/emil-design-eng/SKILL.md`, источник: https://github.com/emilkowalski/skills.

| До | После | Причина |
| --- | --- | --- |
| Segoe UI в мелком тексте меню и Montserrat в редакторе | Bender в DOM, Canvas, титрах и индикаторах | Единая типографика |
| Фиксированный отступ при расчёте высоты редактора | Высота зависит от фактической шапки и окна | Доступная рабочая область |
| Узкие холсты и обрезанные вкладки сцен | Перенос вкладок, вертикальная компоновка на небольших окнах, ограниченная высота списка глав | Доступ к инструментам и читаемое превью |
| Ctrl+Z в поле отменяет редактирование машины/карты | Нативная отмена текстового ввода | Предсказуемая клавиатура |
| Диалог объекта пропускает команды основной карте | Изоляция клавиатуры, замыкание Tab, Esc и возврат фокуса | Диалог управляет собственными действиями |
| Ошибка сохранения объекта видна только за диалогом | Сообщение внутри диалога и возможность повторить | Понятное восстановление после ошибки |
| Повторная запись и правки во время сохранения | Блокировка дублирующей записи и проверка сохранённого снимка | Новые правки не отмечаются сохранёнными |
| Перетаскивание карты остаётся активным при потере фокуса | Завершение при pointercancel и blur | Предсказуемое завершение взаимодействия |

Проверки выполняются в изолированных профилях с перехватом сохранения. Пользовательские ассеты не перезаписываются.

- `npm test`: 459 автоматических тестов.
- `npm run test:editor-ui`: вкладки машины, карты и главы на 1440×900, 1024×768, 800×600 и 640×720; переполнение, подписи полей, Bender, клавиатура, диалог и ошибки сохранения. Дополнительно: все пункты навигации инспекторов, 21 точка миссии и четыре раздела комиксов.
- `npm run test:road-editor`: выбор и вставка точек дороги, undo/redo, перекрёсток и эстакада.
- `npm run test:chapter-editor`: параметры главы, тест с выбранной точки, реплики и возврат.
- `npm run test:editor-draft`: тест существующего и нового черновика, возврат документов, выбора и истории; проверка неизменности файлов на диске.
- `npm run test:menus`: меню, титры, клавиатура, указатель, настройки, звуки и размеры окна.

Результаты: `build/editor-qa-*.log`, `build/editor-ui-check/result.json`; снимки интерфейса в `build/editor-ui-check/`.

Этот проход покрывает перечисленные сценарии. Импорт всех возможных внешних форматов и работа на другом оборудовании не проверялись.
