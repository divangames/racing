# Заготовка под Steam

Сюда позже кладётся `steam_appid.txt` с номером приложения из партнёрки Steam.

Лаунчер уже умеет:

1. Показать клиент, не вкладку браузера.
2. Проверить локальные файлы по `manifest/integrity.json`.
3. Запустить окно заезда.

Дальше, когда будет App ID:

- подключить Steamworks (инициализация, оверлей, облако сейвов);
- выложить депо: клиент Electron + папка `Content` с ассетами;
- «проверить целостность файлов» Steam будет вторым контуром рядом с нашим манифестом.

Пока номер не выдан, файл `steam_appid.txt` не кладём в корень установки — Steam может подхватить чужой тест.
