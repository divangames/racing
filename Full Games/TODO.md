# Задачи клиента

- Движок: хаб, камера, настройки, класс сетки ИИ, серия карьеры, заезд уже в DiVANEngine. Пакеты quarks остаются в `vfx/`. Редактор в exe игрока не выносить. Прогнать `npm test` и `npm run test:engine`.
- DiVANEngine: сплэш `assets/ui/SplashScreen` — версия и текущий файл; не вспыхивает пустым холстом. Запуск — `DiVANEngine.bat`.
- Карта: земля в `Textures/biomes`, полотно в `Textures/road`, борта в `Textures/rails`; масштаб фона в `meta.json`. Сток: по три развязки на биом (клевер / эстакада / турбина), разрывы с трамплином (промах — обочина).
- Кастомные кузова лаборатории — переносимый проект с картинками; карьера уже в `Saves/`.
- Пролог лора в `cats/00`. Кампания, срез 1: комикс → А → 10 000 в Б (с подтверждением) → Б с ложным взносом → ограбление → хлам → первый дивизион. Кузнец в этот срез не входит.
- Заставка: дисклеймер 21+ с VHS сразу при запуске, минимум 5 с, дольше если файлы ещё грузятся. Гейта «любая кнопка» нет. В zip/Content пакуется `assets/ui` (иначе арт не доезжает до игрока).
- Прогон заезда: слои мятости Дьявола 1–6, ближний/дальний Shotgun, пак GTR и дождь над кадром закрыты тестами и `test:engine`. Биом: `embirnt/rain.mp3`, `grom.mp3`, `Snow.mp3`. Живой слух из `Запуск.bat` — на колонках.
- Презентация Pages: ссылка MSI лаунчера живая.
- Проверить `combat-kits.js`, `starter-kits.js`, `mid-kits.js` и `car-audio.js` в Content после синхронизации.
- Прогон 1 дивизиона: сетка ИИ только на кузовах 12–16; 3 дивизион — ещё 17–21. Закрыто тестом сетки и `test:engine`.
- Читы в публичном NSIS-билде скрыты (`cheatsAllowed` / `__RNR_PUBLIC_BUILD__`). Dev-запуск из `Запуск.bat` пункт оставляет.
- Офлайн: музыка из `assets/music/` (титул — папка `cast`) и эффекты из `assets/sounds/FX/`. Десктоп не качает CDN; проверка папок и гейта — `offline-media.test.cjs`. Фон меню — `assets/data/cats/Titles`.
- Полный манифест ассетов (сейчас хешируется ядро, не 8 ГБ картинок).
- Steamworks: App ID, оверлей, облако сейвов.
- Ключевой арт лаунчера: ролик `launcher-hero.mp4` и кадр `launcher-hero.webp` (2560×1440, окно 1280×720).
- Лаунчер: zip игры с GitHub — сделано; самообновление MSI при старте (канал `launcher-*`, msiexec + UAC, ProductVersion из четырёх цифр) — сделано; остался Steam-депо.
- Собрать MSI и выложить первый `game-*` релиз с zip.
- Выложить контент: `Выложить-игру.bat` или в чате «Обнови игру» (новый номер = кнопка обновления).
- Подпись exe и иконка 256×256.
- Заменить заглушки установщика в `assets/install` на финальный арт (размеры в README папки).
- Для сайта без SmartScreen — купить OV/EV Code Signing и подменить `certs/divan-games.pfx`.
