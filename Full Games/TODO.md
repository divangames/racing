# Задачи клиента

- Пролог: положить `01.webp`–`07.webp` в `assets/data/cats/00`.
- Сюжет Скарабея пока только в каноне корня (`assets/data/players/DOCK.md`); в клиент не внедрён.
- Прогнать заезд из лаунчера: меню, гараж, гонка, звук; погода quarks без капель на камере.
- Презентация Pages: ссылка Диска и `rnr.html` живые.
- Проверить `combat-kits.js` и `starter-kits.js` в Content после синхронизации.
- Прогнать 1 дивизион: сетка ИИ только на кузовах 12–16; в гараже лаборатории «личность авто» — рост НПС `07`–`12`, не портрет.
- Спрятать читы в публичном NSIS-билде.
- Проверить офлайн: музыка из `assets/music/` и эффекты из `assets/sounds/FX/` (без сети, кроме отсутствующих файлов).
- Полный манифест ассетов (сейчас хешируется ядро, не 8 ГБ картинок).
- Steamworks: App ID, оверлей, облако сейвов.
- Ключевой арт лаунчера: `assets/image/launcher-hero.webp`, 2560×1440 (окно 1280×720).
- Лаунчер: ремонт файлов / докачка с GitHub — сделано; остался Steam-депо.
- Собрать MSI и выложить первый `game-*` релиз с zip.
- Выложить контент: `Выложить-игру.bat` и ввести номер (новый = обновление, тот же = замена zip).
- Подпись exe и иконка 256×256.
- Заменить заглушки установщика в `assets/install` на финальный арт (размеры в README папки).
- Для сайта без SmartScreen — купить OV/EV Code Signing и подменить `certs/divan-games.pfx`.
