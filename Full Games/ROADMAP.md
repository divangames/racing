# План клиента

Браузерная версия остаётся рабочей веткой контента. Десктоп — оболочка к установке и Steam.

## Сейчас

Клиент читает ту же игру. MSI ставит лаунчер в `C:\games\Divan Games\Колесница войны`. Zip игры — тег `game-*`, сам лаунчер — тег `launcher-*`; оба качаются с GitHub. Публичная презентация — GitHub Pages.

## Дальше

1. Офлайн-пакет: музыка из `assets/music/` (в том числе `Load` для пролога), эффекты из `assets/sounds/FX/`; добить отсутствующие гоночные MP3 и шрифты только с диска.
2. Депо Steam: `Колесница войны.exe` + `Content/`.
3. Если zip больше 2 ГБ — части архива.
4. Античит и проверка файлов на старте сессии — после онлайна.

Не переносить сюда лабораторию с записью `car.json`, пока десктоп не станет основной машиной команды.
