# Колесница войны — десктоп-клиент

В режиме разработки клиент **читает** соседнюю папку игры. `Лаборатория.bat` открывает редактор машин и трасс, пишет `car.json`, JSON трасс и ассеты `*.labr` туда же.

Это не вкладка Chrome. Окно Electron, протокол `rnr://`, сохранения в профиле Windows (`userData`), проверка ядра по SHA-256.

## Структура

- `src/main/` — процесс клиента: окна, протокол, целостность
- `src/engine/story-campaign.js` — кампания Медведя: stolen Camaro, времянка
- `src/engine/story-hunt.js` — охота на Бронекузнеца: заводской трек, босс, корпус за 1 место
- `src/engine/story-repair.js` — ходовая на овале, ручной режим без чёрного ящика
- `src/engine/story-invite.js` — пропуск на арену, Янот в сетке
- `src/engine/story-family.js` — Ерш и Бегемотик на табло, без убийства своих
- `src/main/player-store.js` — слоты карьеры в `%userData%/Saves`
- `src/main/engine-host.js` — какой HTML получает движок
- `config/engine.json` — ABI, схема контента, список модулей
- `config/game.json` — имя, версия, точка входа, флаг `runtime`
- `src/main/editor-enhancements.js` — расширяет текущий редактор, сохраняя его библиотеку объектов
- `src/launcher/` — экран запуска (левый столбец команд, центр — арт)
- `src/preload/` — мост без Node в странице
- `world-intro.js` — лор арены после «любая кнопка»; сюжет Медведя — `assets/data/cats/campaign/` и меню «Кампания»
- `armory.js` — оружейка, копируется так же
- `manifest/integrity.json` — список ядра для проверки
- `vendor-local/` — Three и quarks без CDN
- Контент игры: `vfx/quarks-weather.js` (дождь / снег / буря / извержение), `vfx/weather-fx.js` (молния, дымка), `vfx/quarks-spray.js` (снег и вода из-под колёс), `vfx/quarks-wreck.js` (дым и огонь с подбитого корпуса)
- `steam/` — заготовка под App ID и депо
- `Запуск.bat` — лаунчер
- `Лаборатория.bat` — внутренний редактор, не из лаунчера
- `Собрать-билд.bat` — готовая папка `dist/win-unpacked` (exe + Content)
- `Доверить-Divan-Games.bat` — чтобы этот Windows не ругался на издателя
- `Собрать-MSI.bat` — установщик лаунчера без игры
- `Выложить-игру.bat` — zip игры в GitHub Releases (`game-*`)
- `Выложить-лаунчер.bat` — MSI лаунчера в GitHub Releases (`launcher-*`). Уже установленный клиент качает его сам.
- В чате Cursor те же выкладки: **Обнови игру**, **Обнови лаунчер**, **Полное обновление**.
- `Собрать-установщик.bat` — NSIS x64
- `Проверить-файлы.bat` — пересобрать манифест
- `Синхронизировать-контент.bat` — копия кода в `dist-content`

Ассеты в разработке читаются из соседней папки. **Сборка для другого человека** копирует их в `Content` целиком. Кузова — `assets/data/cars/NN/` (`NN.webp`, броня в `armor/`, повреждения в `damage/`; у Дьявола — `01_damage_1`…`6`). Музыка — файлы в `assets/music/{main,change,garage,intro,racing,Load,cast}/` (десктоп без CDN). Титул играет `cast`. Эффекты — `assets/sounds/FX/`. Мотор и шины — WAV в `assets/sounds/engine`, `assets/sounds/cars/wheels` и паках `assets/sounds/cars/engine`; клиент отдаёт их по `rnr://` целиком. Дождь quarks рождается над кадром, не на линзе.

## Запуск

Нужны Node.js 20+ и npm.

1. Дважды `Запуск.bat` (первый раз поставит Electron).
2. Лаунчер проверит файлы. Если окно заезда не открылось — лаунчер останется на экране.
3. «Играть» открывает заезд; полный экран включается после загрузки (кнопка переключает окно). Фон, логотип и музыка Load уже внутри лаунчера, лаборатории в меню нет.

Центр лаунчера: ролик `assets/image/launcher-hero.mp4`, в конце белая вспышка и кадр `launcher-hero.webp` (**2560×1440**), через 5 секунд ролик снова. Копируются в `src/launcher/media/` скриптом `npm run media`.

Правка машин и трасс: `Лаборатория.bat` (Ctrl+S пишет `car.json` или JSON трассы; ассеты — пак `*.labr`). В машине: пак двигателя и звуки ствола/ульты. Браузерный `editor.bat` не трогали.

Или из этой папки: `npm install` и `npm start`.

Браузерный `start.bat` по-прежнему открывает игру во вкладке — его не трогали.

## Сборка

`Собрать-билд.bat` — папка `Full Games/dist/win-unpacked`: exe, лаунчер, рантайм и **лаборатория** в `Content`. Без `assets/Материалы` и исходников.

`Собрать-MSI.bat` — лёгкий MSI **только лаунчера**, подписанный как **Divan Games**. Мастер на русском, по умолчанию ставит в `C:\games\Divan Games\Колесница войны`. Корень можно выбрать, хвост `Divan Games\Колесница войны` не снимается. Ярлык — «Колесница Войны». Картинки мастера — `assets/install/` (см. README там). Один раз запусти `Доверить-Divan-Games.bat`, иначе свой же ПК может показать «неизвестный издатель».

`Собрать-установщик.bat` — NSIS без 8 ГБ внутри. Для чужого ПК с уже лежащим Content нужен `Собрать-билд.bat`. Упакованный заезд не показывает пункт «ЧИТЫ»; из `Запуск.bat` он остаётся.

## Деплой для сайта

Презентация на GitHub Pages: https://divangames.github.io/racing/  
Скачать лаунчер: https://github.com/divangames/racing/releases/download/launcher-0.2.2.6/KolesnicaVoyny-0.2.2.6.msi

На сайте отдаём MSI лаунчера. Игра — отдельный zip в GitHub Releases. После первой установки лаунчер обновляет **сам себя** с тега `launcher-*`, игру — с тега `game-*`.

1. `Выложить-игру.bat` спрашивает номер (или `Выложить-игру.bat 0.2.2`). Пишет только `config/game.json`. Тег `game-ВЕРСИЯ`, файл `kolesnica-content-ВЕРСИЯ.zip`. Новый номер — кнопка «Обновить игру»; тот же — zip перезапишется. В чате: «Обнови игру» (номер сам поднимается, либо укажи его в сообщении).
2. `Выложить-лаунчер.bat` спрашивает номер оболочки (или аргумент). Пишет `config/launcher.json` и `package.json`, собирает MSI, заливает тег `launcher-ВЕРСИЯ`, файл `KolesnicaVoyny-ВЕРСИЯ.msi`. Игроки со старым лаунчером (уже с этой функцией) скачают MSI, установщик сменит файлы, клиент откроется снова. В чате: «Обнови лаунчер». Оба канала сразу — «Полное обновление».
3. Имя zip **обязательно** начинается с `kolesnica-content` и заканчивается на `.zip`. MSI — с `KolesnicaVoyny` и `.msi`.
4. Четыре цифры (`0.2.1.3`): игра живёт в `game.json`; лаунчер — в `launcher.json`; npm для electron-builder получает `0.2.1-3`.
5. Игрок ставит MSI один раз с сайта. Дальше zip и новые MSI качаются сами. «Играть» оживает после установки игры. Обновление лаунчера закрывает окно на время msiexec.
6. Первая установка MSI всё ещё нужна тем, у кого лаунчер старше автообновления оболочки.

GitHub не принимает один файл больше **2 ГБ**. Если пакет толще — урежь «Материалы» (их и так нет в zip) или режь ассеты. Репозиторий и префикс файла задаются в `config/update.json`.

Нужны: Node 20+, для MSI интернет (WiX), для публикации — `gh auth login`. Steam по-прежнему позже: `steam/README.md`.

## Технологии

- Electron
- electron-builder (NSIS и MSI)
- HTML5 Canvas / `rnr.html` как контент; десктоп вешает версионированный `DiVANEngine` (рантайм `html-legacy`)
- GitHub Releases: zip игры (`game-*`) и MSI лаунчера (`launcher-*`); клиент качает оба сам
- Музыка не качается отдельно: она внутри `kolesnica-content*.zip`, папки `assets/music/{main,change,garage,intro,racing,Load,cast}`. Индекс — `rnr://game/__music-index`. Браузерная версия при отсутствии файла может взять запас с ikrinka24; десктоп — только диск.
- SHA-256 манифест ядра

## Доработки движка и проверка

Изменения движка включаются через `Запуск.bat`, `npm run start:game` и `Лаборатория.bat`. Существующий exe из прежнего `dist` не обновляется автоматически от изменения исходников клиента.

`npm test` запускает регрессии сохранения, истории, маршрутизации, упаковки и обновлений. `npm run test:engine` проверяет настоящий Electron в скрытых окнах: полигон, гонку с пятью машинами, редакторы машин и карт. Во время этой проверки все серверные операции записи подменены: исходные машины, трассы и объекты не меняются. Кадры и результаты лежат в `build/engine-check/`.

В редакторе карты доступны импорт/экспорт JSON и восстановление локального черновика. Импорт создаёт отдельную неопубликованную трассу. Отмена/повтор относятся к выбранному документу. Файлы `.previous` рядом с JSON содержат предыдущую версию; удалённые карты находятся в `assets/data/tracks/.trash/`.

Архитектура, ограничения и оставшаяся работа описаны в [ENGINE.md](ENGINE.md).
