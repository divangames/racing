# Колесница войны — десктоп-клиент

Код игры и редактора находится в `content/` внутри десктопного проекта. Браузерная копия убрана: старые `start.bat` и `local-server.bat` открывают приложение, а адреса `rnr.html` и `Editor.html` ведут на скачивание. `DiVANEngine.bat` открывает редактор машин и трасс (окно Electron), пишет `car.json`, JSON трасс и ассеты `*.labr` в общую библиотеку `../assets`. Паки ассетов имеют свой цвет и могут образовывать дерево; системные паки защищены от переноса и удаления. Все остальные действия собраны в `Проект.bat`.

`npm install` создаёт стык `content/assets` на общую библиотеку: картинки, звук и авторские настройки не дублируются. Восстановить его отдельно: `npm run content:prepare`. Упаковка включает реальные ассеты в `Content`; установленная игра не требует исходного проекта. GitHub Pages собирает только презентацию через `tools/build-site.cjs`, без игрового кода.

Это не вкладка Chrome. Окно Electron, протокол `rnr://`, сохранения в профиле Windows (`userData`), проверка ядра по SHA-256.

Меню игры оформлены в едином стиле: тёмные металлические панели, спокойные холодные акценты, плавное выделение и короткие переходы. Мышь работает в обеих паузах и слотах сохранения; громкость и силу тряски можно менять перетаскиванием. Короткие механические звуки меню регулируются ползунком эффектов. Системная настройка уменьшения движения отключает новые анимации. `npm run test:menus` проверяет экраны и ввод в скрытом Electron с отдельным профилем; снимки и отчёт находятся в `build/menu-design-check/`.

Звук демонстраций автомобиля отключён. В паузе гонка замолкает, а интерфейс продолжает звучать; музыка плавно становится тише. Настройки используют фон главного меню без старого синтезированного трека. Моторы и оружие расположены в стерео по стороне экрана. Проверка `npm run test:audio-balance` измеряет реальный сигнал левого/правого каналов, наведение в паузе, отключение звука и тишину демонстраций; отчёт — `build/audio-balance-check/result.json`.

## Запуск

Нужны Node.js 20+ и npm.

1. Дважды `Запуск.bat` (первый раз поставит Electron).
2. Лаунчер проверит файлы. Если окно заезда не открылось — лаунчер останется на экране.
3. «Играть» открывает заезд; полный экран включается после загрузки (кнопка переключает окно). Фон, логотип и музыка Load уже внутри лаунчера, лаборатории в меню нет.

Центр лаунчера: ролик `assets/image/launcher-hero.mp4`, в конце белая вспышка и кадр `launcher-hero.webp` (**2560×1440**), через 5 секунд ролик снова. Копируются в `src/launcher/media/` скриптом `npm run media`.

Правка машин и трасс: `DiVANEngine.bat` (Ctrl+S пишет `car.json` или JSON трассы; ассеты — пак `*.labr`). В машине: пак двигателя и звуки ствола/ульты. `editor.bat` в корне игры запускает то же окно, не Chrome.

Свет автомобиля: выберите машину и нажмите «Фары и стопы» под холстом или «Свет» вверху правой панели. Перетаскивайте точки на кузове либо задавайте X/Y. Нос автомобиля направлен по +X; координаты общие с колёсами и нитро, ручные точки не масштабируются повторно вместе с кузовом. Можно редактировать передние фары и стоп-сигналы, добавить до восьми точек каждого типа, создать зеркальную копию и двигать парные точки вместе. Стрелки сдвигают выбранную точку на 0,5, Shift+стрелки — на 0,1; Escape отменяет текущий жест, Ctrl+Z / Ctrl+Y отменяют и возвращают шаги.

«Автоматически» возвращает выбранную группу к положению по размеру кузова/брони; удаление всех точек выключает эту группу. Предпросмотр света и торможения не меняет документ. Правки автоматически пишутся в рабочий `car.json`, а «Сохранить» или Ctrl+S также обновляет базовый вариант для сброса. Свет сохраняется отдельно у каждого автомобиля и используется в гонке. Состояние записи видно в закреплённой шапке панели; разделы «Машины / Слои / Свет / Параметры» открываются оттуда же.

Проверка `npm run test:car-lights` открывает скрытый редактор Electron, проверяет перетаскивание, отмену, сохранение/перезагрузку, разные размеры окна и совпадение света с игрой. Запись идёт только в временную папку проверки; хэши исходных настроек машин сверяются до и после.

В редакторе карты выберите «Править дорогу»: голубые точки перемещаются перетаскиванием, двойной щелчок по пунктирной оси вставляет точку в этот участок. Щелчок вне дороги ничего не добавляет. В правой панели можно задать координаты, включить сетку и выбрать тип пересечения: перекрёсток на одном уровне или эстакаду. Кнопки «Новая магистраль» и «Новый перекрёсток» создают отдельные черновики замкнутой трассы; это пока один маршрут круга, без развилок для выбора пути.

Или из этой папки: `npm install` и `npm start`.

Старый `start.bat` запускает то же десктопное приложение; отдельного браузерного запуска больше нет.

## Сборка

Пункт «Собрать портативный билд» в `Проект.bat` создаёт `Full Games/dist/win-unpacked`: exe, лаунчер, рантайм и **лабораторию** в `Content`. Без `assets/Материалы` и исходников.

Пункт «Собрать MSI-установщик» — лёгкий MSI **только лаунчера**, подписанный как **Divan Games**. Мастер на русском, по умолчанию ставит в `C:\games\Divan Games\Колесница войны`. Корень можно выбрать, хвост `Divan Games\Колесница войны` не снимается. Ярлык — «Колесница Войны». Картинки мастера — `assets/install/` (см. README там). Один раз выбери в меню «Доверить сертификату Divan Games», иначе свой же ПК может показать «неизвестный издатель».

Пункт «Собрать EXE-установщик» — NSIS без 8 ГБ внутри. Для чужого ПК с уже лежащим Content нужен портативный билд. Упакованный заезд не показывает пункт «ЧИТЫ»; из `Запуск.bat` он остаётся.

## Деплой для сайта

Презентация на GitHub Pages: https://divangames.github.io/racing/  
Скачать лаунчер: https://github.com/divangames/racing/releases/download/launcher-0.2.2.13/KolesnicaVoyny-0.2.2.13.msi

На сайте отдаём MSI лаунчера. Игра — отдельный zip в GitHub Releases. После первой установки лаунчер обновляет **сам себя** с тега `launcher-*`, игру — с тега `game-*`.

1. Пункт «Выложить игру» в `Проект.bat` спрашивает номер. Пишет только `config/game.json`. Тег `game-ВЕРСИЯ`, файл `kolesnica-content-ВЕРСИЯ.zip`. Новый номер — кнопка «Обновить игру»; тот же — zip перезапишется. В чате: «Обнови игру» (номер сам поднимается, либо укажи его в сообщении).
2. `Проект.bat` — единое меню запуска, сборок, релизов и Git. Pages, диздок, commit и push можно запускать по отдельности или все вместе. Выкладка лаунчера предлагает версию (Enter / `+` / номер), собирает MSI и обновляет ссылки на сайтах.
3. Имя zip **обязательно** начинается с `kolesnica-content` и заканчивается на `.zip`. MSI — с `KolesnicaVoyny` и `.msi`.
4. Четыре цифры (`0.2.1.3`): игра живёт в `game.json`; лаунчер — в `launcher.json`; npm для electron-builder получает `0.2.1-3`.
5. Игрок ставит MSI один раз с сайта. При следующем запуске лаунчер **сам** проверяет тег `launcher-*`: если оболочка новее — качает MSI, просит права администратора, ставит и открывается снова. Zip игры качается отдельно, без переустановки клиента. «Играть» оживает после установки игры.
6. Первая установка MSI всё ещё нужна тем, у кого лаунчер старше автообновления оболочки.

GitHub не принимает один файл больше **2 ГБ**. Если пакет толще — урежь «Материалы» (их и так нет в zip) или режь ассеты. Репозиторий и префикс файла задаются в `config/update.json`.

Нужны: Node 20+, для MSI интернет (WiX), для публикации — `gh auth login`. Steam по-прежнему позже: `steam/README.md`.

## Доработки движка и проверка

### Заезд: управление, бой и повтор

Лёгкие, тяжёлые и спортивные машины отличаются массой, торможением и пределом сцепления. Занос зависит от скорости и покрытия, стабилизируется контррулением и плавным выходом на газ; дым и звук шин следуют реальному скольжению. Нитро добавляет тягу, но теряет эффективность на льду, масле и в сильном заносе. Выключение погодных эффектов не меняет сцепление.

Соперники используют агрессивный, осторожный и техничный стили, тормозят перед поворотами и выбирают полосу обгона. Столкновения учитывают массу и скорость сближения; разъезжающиеся машины не получают повторный урон. Тяжёлое оружие показывает подготовку выстрела с зафиксированным направлением, а самонаводящийся снаряд можно обмануть сменой траектории. На тактических поворотах внутренняя дуга короче, но содержит разрушаемое ограждение и опасный сектор; внешняя свободна от этих препятствий.

После финиша показаны лучший круг, точность снарядов, фактический урон, время заноса, уничтожения и возвраты. **R** на экране результатов повторяет ту же трассу с тем же составом и характеристиками участников, без новых наград и продвижения карьеры. Личный призрак чистого лучшего круга доступен в полигоне и повторе; **G** включает его отображение, если клавиша не занята другим действием. Рекорды разделены по трассе, машине, тюнингу и условиям заезда.

**T** возвращает застрявшую машину на свободный участок текущей или пройденной части трассы. Возврат доступен также через паузу, перезаряжается 5 секунд, сохраняет повреждения, боезапас и перезарядки; текущий круг исключается из рекордов. Клавишу можно переназначить в настройках управления. В разделе «Графика» есть «Сила тряски» от 0 до 100%.

`npm run test:race-upgrade` проверяет эти функции вместе в скрытом Electron с отдельным профилем: движение ИИ, заряд, возврат, запись и воспроизведение призрака, результаты, повтор и настройку тряски. Снимки экранов и отчёт находятся в `build/race-upgrade-check`.

Изменения движка включаются через `Запуск.bat`, `npm run start:game` и `DiVANEngine.bat`. Существующий exe из прежнего `dist` не обновляется автоматически от изменения исходников клиента.

`npm test` запускает регрессии сохранения, истории, маршрутизации, упаковки и обновлений. `npm run test:engine` проверяет настоящий Electron в скрытых окнах: полигон, гонку с пятью машинами, редакторы машин и карт. `npm run test:audio` через настоящий `rnr://` проверяет, что дождь в меню, а дождь и трибуна в заезде не только загружаются, но и реально находятся в состоянии воспроизведения с ненулевой громкостью. Во время проверок операции записи подменены: исходные машины, трассы и объекты не меняются.

В редакторе карты доступны импорт/экспорт JSON, восстановление локального черновика и прямая загрузка текстур дороги/бортов. Выбранные объекты копируются через Ctrl+C/Ctrl+V, дублируются, отражаются и получают точный размер с фиксацией пропорций. В редакторе объекта новая картинка вписывается в прежний размер, а изменение габаритов масштабирует коллизии. Контур, вершины и ручки размера коллизии видны даже при временно выключенном столкновении; режимы выбора и добавления вершин разделены. Тест трассы умеет запускать 1–4 соперников с выбранной сложностью и числом кругов. Обычные трассы и трассы кампании выбираются в разных пунктах правой панели. Импорт JSON создаёт отдельную неопубликованную трассу. Отмена/повтор относятся к выбранному документу. Файлы `.previous` рядом с JSON содержат предыдущую версию; удалённые карты находятся в `assets/data/tracks/.trash/`.

«Тест черновика» запускает текущую геометрию без записи JSON трассы. Возврат из заезда восстанавливает затронутые документы, отмену/повтор, выбранный инструмент и выделение. Для записи на диск нужна отдельная команда «Сохранить» / Ctrl+S. Временный сеанс теста не заменяет резервную копию; при нехватке места переход блокируется с сообщением.

`npm run test:editor-draft` проверяет в скрытом Electron тест существующей и новой несохранённой трассы, возврат документов и истории, отсутствие записей при тестировании и отдельный вызов явного сохранения. Запись трасс и машин подменена, результаты и снимки находятся в `build/draft-test-check/`.

Архитектура, ограничения и оставшаяся работа описаны в [ENGINE.md](ENGINE.md).

## Тактические события трасс

На 15 штатных трассах есть выбранный поворот с двумя размеченными траекториями: внутренняя действительно короче, внешняя не получает воздействия нового события. Пресс замедляет и повреждает машину, жар повреждает корпус, охладитель временно снижает сцепление. Перед активной фазой — четыре секунды предупреждения. Оружие соперников и ручные препятствия остаются опасными на обеих полосах. ИИ учитывает окно и запас корпуса; старые портальные срезы на таких трассах отключены.

В редакторе поле «Тактика арены» включает сценарий или выбирает его по биому. Кампания и пользовательские карты без этой настройки не меняются. После изменения геометрии участок подбирается заново; если подходящего плавного поворота без моста и разрыва нет, событие не включается. Выбор входит в JSON, отмену/повтор и тест черновика. Это первая итерация внутри существующей дороги: отдельные ветки маршрута и постановка уникальных событий ещё впереди.

`npm run test:track-tactics` проверяет настройку в редакторе, тестовый заезд, безопасность внешней полосы от события, одинаковое воздействие на игрока и ИИ и возврат документа без сохранения. Артефакты: `build/track-tactics-check/`. Для окончательной настройки циклов нужны ручные заезды разными машинами.

## Управление и боевой HUD

У стандартного геймпада левый стик отвечает за руль, RT/R2 — за газ, LT/L2 — за тормоз и задний ход. A/крест — оружие, B/круг — нитро, X/квадрат — ульта, Y/треугольник — ручник, Start/Options — пауза. Газ дозирует ускорение; руль плавно возвращается в центр. После паузы или Alt+Tab отпустите удержанные кнопки и курки перед продолжением. Раскладка клавиатуры сохраняется и переназначается в настройках.

В гараже у каждого улучшения показана реальная прибавка следующего уровня. Тренировки характеристик стоят 900/1800/3200/5200, навыка и дохода — 1200/2400/4200/7200/12000. Финиш вне подиума в календаре приносит минимум 25/20/15% приза победителя за 4/5/6+ место; сходы и реванши не получают эту доплату.

Игра и сайт используют один пользовательский файл `assets/HUD/cursor/cursor.png` размером 42×42 для обычного наведения, кнопок и ссылок. Текстовые поля сохраняют стандартный курсор ввода.

На 4K масштаб HUD увеличивается вместе с разрешением: приборы, диалоги и текст вдвое крупнее, чем на Full HD, при той же доле экрана. Проверка `npm run test:combat-feel` снимает интерфейс в семи разрешениях, включая 3840×2160.

Панели проходят через общий прозрачный слой с цилиндрическим искривлением и лёгкой бочкообразной дисторсией: центр почти ровный, края выгибаются наружу. Проекция удерживает панели в кадре. Эффект применяется только к HUD, оставляя игровой мир и маркеры машин без искажения. При недоступном WebGL сохраняется обычный Canvas-интерфейс. Корпус и диалоги имеют одинаковую ширину и отступы; имена и реплики стоят в общей колонке.

Настройка управляемости охватывает все 21 штатный кузов: лёгкие, универсальные, спортивные, грузовые, внедорожные и специальные варианты. Три опорных профиля сохранены: «Курьер» — лёгкий и отзывчивый; «Грязевой дьявол» — универсальный; «Чёрный молот» — спокойнее в поворотах и требует более раннего торможения. «Шпилька» дольше удерживает занос для своего оружия, «Аэро-клинок» сохраняет ховер без колёсного ручника и сноса. Экономика, здоровье, мощность и способности не изменены. Камера учитывает боковое движение, не меняя сохранённый зум.

Пользовательские кузова из редактора получают профиль автоматически: ховер имеет приоритет, затем тяжёлый при базовом корпусе ≥125, спортивный при коэффициенте скорости ≥1,12, лёгкий при корпусе ≤85, иначе универсальный. Это подбор поведения, а не изменение введённых характеристик. Переключение ховера и изменения параметров учитываются без кэширования старого профиля. У штатных колёсных машин сохраняются индивидуальные настройки.

В заезде включён компактный киберпанк-HUD. Слева сверху — корпус и активная защита, по центру — место, таймер и круг; справа — уничтожения и собранные деньги. Внизу разнесены небольшие приборы скорости, оружия/способностей и карта. Оружие, ульта и ускоритель имеют по одной ячейке с назначенной клавишей и фактическим состоянием. HUD использует средний размер: панели и текст увеличены примерно на треть относительно компактной версии. Слева внизу — круговой спидометр с неоновой дугой, насечками и крупными цифрами. Масштаб ограничен отдельно от камеры, маленькие окна сохраняют адаптивную компоновку. Полигон показывает лучшее и прошлое время круга.

Выноски игрока и соперников появляются слева под корпусом: имя, портрет и реплика из штатной голосовой очереди. Они работают и при скрытой таблице, до двух одновременно, учитывают срок жизни, перенос текста и настройку уменьшения движения. **F6** открывает/скрывает таблицу позиций справа; выбор сохраняется. Если F6 назначена на управление, это назначение имеет приоритет. Голубые скобки выделяют игрока, красные шкалы — видимых соперников, ромбы — до трёх ближайших угроз; дуга указывает направление удара. Над игроком и видимыми NPC показано актуальное место из общего порядка гонки: голубая метка «N · ВЫ» и красная «N МЕСТО». Постоянная панель задачи, дубли нитро и оружия, слоганы и повторная лента событий убраны.

`npm run test:combat-feel` запускает отдельный профиль Electron, измеряет торможение/поворот/снос на реальных характеристиках всего загруженного автопарка, проверяет прямую на мокром льду и состояния оружия, снимает HUD в семи размерах окна, включая 4K, и в состояниях повреждения, перезарядки, восстановления, эфира, старта и паузы. Дополнительно проверяет площадь панелей, диалоги обоих гонщиков через штатный voiceSay, полный режим, маленькое окно и истечение реплик. У «Шпильки» HUD показывает «НУЖЕН ЗАНОС», если условие выстрела не выполнено. Отчёт и изображения: `build/combat-feel-check/`. Это проверяемая базовая настройка, а не подтверждение окончательного игрового баланса: для него нужны ручные заезды, в том числе на геймпаде.
