# Колесница войны — десктоп-клиент

В режиме разработки клиент **читает** соседнюю папку игры. `Лаборатория.bat` открывает редактор машин и трасс, пишет `car.json`, JSON трасс и ассеты `*.labr` туда же.

Это не вкладка Chrome. Окно Electron, протокол `rnr://`, сохранения в профиле Windows (`userData`), проверка ядра по SHA-256.

## Структура

- `src/main/` — процесс клиента: окна, протокол, целостность
- `src/engine/` — доработки десктоп-игры: фиксированный шаг, управление, HUD, частицы и звук
- `src/main/editor-enhancements.js` — расширяет текущий редактор, сохраняя его библиотеку объектов
- `src/launcher/` — экран запуска (левый столбец команд, центр — арт)
- `src/preload/` — мост без Node в странице
- `world-intro.js` — пролог из семи кадров после «любая кнопка»; кадры в `assets/data/cats/00`
- `armory.js` — оружейка, копируется так же
- `config/game.json` — имя, версия, точка входа
- `manifest/integrity.json` — список ядра для проверки
- `vendor-local/` — Three и quarks без CDN
- Контент игры: `vfx/quarks-weather.js` (дождь / снег / буря / извержение), `vfx/weather-fx.js` (молния, дымка), `vfx/quarks-spray.js` (снег и вода из-под колёс)
- `steam/` — заготовка под App ID и депо
- `Запуск.bat` — лаунчер
- `Лаборатория.bat` — внутренний редактор, не из лаунчера
- `Собрать-билд.bat` — готовая папка `dist/win-unpacked` (exe + Content)
- `Доверить-Divan-Games.bat` — чтобы этот Windows не ругался на издателя
- `Собрать-MSI.bat` — установщик лаунчера без игры
- `Выложить-игру.bat` — zip контента в GitHub Releases; версию пишешь сам. Zip собирается за секунды; дальше только заливка на GitHub.
- `Собрать-установщик.bat` — NSIS x64
- `Проверить-файлы.bat` — пересобрать манифест
- `Синхронизировать-контент.bat` — копия кода в `dist-content`

Ассеты в разработке читаются из соседней папки. **Сборка для другого человека** копирует их в `Content` целиком. Кузова — `assets/data/cars/NN/` (`NN.webp`, броня в `armor/`). Музыка — все файлы в `assets/music/{main,change,garage,intro,racing}/`, эффекты — `assets/sounds/FX/`.

## Запуск

Нужны Node.js 20+ и npm.

1. Дважды `Запуск.bat` (первый раз поставит Electron).
2. Лаунчер проверит файлы. Если окно заезда не открылось — лаунчер останется на экране.
3. «Играть» открывает заезд; полный экран включается после загрузки (кнопка переключает окно). Фон, логотип и музыка Load уже внутри лаунчера, лаборатории в меню нет.

Центр лаунчера ждёт файл `assets/image/launcher-hero.webp` (**2560×1440**, WebP) на всё окно 1280×720.

Правка машин и трасс: `Лаборатория.bat` (Ctrl+S пишет `car.json` или JSON трассы; ассеты — пак `*.labr`). Браузерный `editor.bat` не трогали.

Или из этой папки: `npm install` и `npm start`.

Браузерный `start.bat` по-прежнему открывает игру во вкладке — его не трогали.

## Сборка

`Собрать-билд.bat` — папка `Full Games/dist/win-unpacked`: exe, лаунчер, рантайм и **лаборатория** в `Content`. Без `assets/Материалы` и исходников.

`Собрать-MSI.bat` — лёгкий MSI **только лаунчера**, подписанный как **Divan Games**. Мастер на русском, по умолчанию ставит в `C:\games\Divan Games\Колесница войны`. Корень можно выбрать, хвост `Divan Games\Колесница войны` не снимается. Ярлык — «Колесница Войны». Картинки мастера — `assets/install/` (см. README там). Один раз запусти `Доверить-Divan-Games.bat`, иначе свой же ПК может показать «неизвестный издатель».

`Собрать-установщик.bat` — NSIS без 8 ГБ внутри. Для чужого ПК с уже лежащим Content нужен `Собрать-билд.bat`.

## Деплой для сайта

Презентация на GitHub Pages: https://divangames.github.io/racing/  
Скачать клиент: https://disk.yandex.ru/d/BHvSSYPNRSt8cQ

На сайте отдаём MSI лаунчера. Игра — отдельный zip в GitHub Releases.

1. `Выложить-игру.bat` спрашивает номер (или `Выложить-игру.bat 0.2.2`). Новый номер — лаунчер увидит обновление; тот же — zip на этом теге перезапишется. Пишет версию в `config/game.json`, собирает `kolesnica-content-ВЕРСИЯ.zip` (без второй копии дерева и без сжатия уже сжатых ассетов), тег `game-ВЕРСИЯ` в https://github.com/divangames/racing/releases
2. Имя файла **обязательно** начинается с `kolesnica-content` и заканчивается на `.zip`
3. `Собрать-установщик.bat` / `Собрать-MSI.bat` — exe/msi. Четыре цифры версии (`0.2.1.3`) живут в `game.json`; npm для electron-builder получает `0.2.1-3`.
4. Игрок ставит MSI, лаунчер при старте качает zip, показывает прогресс и скорость, пишет игру в профиль Windows. «Играть» оживает после установки.
5. Следующий zip с более новым тегом — лаунчер сам предлагает обновление.

GitHub не принимает один файл больше **2 ГБ**. Если пакет толще — урежь «Материалы» (их и так нет в zip) или режь ассеты. Репозиторий и префикс файла задаются в `config/update.json`.

Нужны: Node 20+, для MSI интернет (WiX), для публикации — `gh auth login`. Steam по-прежнему позже: `steam/README.md`.

## Технологии

- Electron
- electron-builder (NSIS и MSI)
- HTML5 Canvas / тот же `rnr.html`, без переписывания движка
- GitHub Releases: zip игры, лаунчер качает сам
- Музыка не качается отдельно: она внутри `kolesnica-content*.zip`, папки `assets/music/{main,change,garage,intro,racing,Load}`. Индекс — `rnr://game/__music-index`. Браузерная версия при отсутствии файла может взять запас с ikrinka24; десктоп — только диск.
- SHA-256 манифест ядра

## Доработки движка и проверка

Изменения движка включаются через `Запуск.bat`, `npm run start:game` и `Лаборатория.bat`. Существующий exe из прежнего `dist` не обновляется автоматически от изменения исходников клиента.

`npm test` запускает регрессии сохранения, истории, маршрутизации, упаковки и обновлений. `npm run test:engine` проверяет настоящий Electron в скрытых окнах: полигон, гонку с пятью машинами, редакторы машин и карт. Во время этой проверки все серверные операции записи подменены: исходные машины, трассы и объекты не меняются. Кадры и результаты лежат в `build/engine-check/`.

В редакторе карты доступны импорт/экспорт JSON и восстановление локального черновика. Импорт создаёт отдельную неопубликованную трассу. Отмена/повтор относятся к выбранному документу. Файлы `.previous` рядом с JSON содержат предыдущую версию; удалённые карты находятся в `assets/data/tracks/.trash/`.

Архитектура, ограничения и оставшаяся работа описаны в [ENGINE.md](ENGINE.md).
