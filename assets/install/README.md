# Картинки установщика MSI

Сюда кладёшь финальный арт. Размеры **жёсткие**: WiX иначе криво режет кадр.
Скрипт `Full Games/tools/make-installer-art.py` рисует заглушки, если файла ещё нет.
`Собрать-MSI.bat` копирует всё в `Full Games/build/msi`.

Формат баннеров — **BMP 24 бит, без альфы**. Иконки — **ICO**.

| Файл | Размер | Куда в окне |
| --- | --- | --- |
| `banner.bmp` | **493 × 58** | Узкая полоса сверху (Welcome, путь, прогресс) |
| `dialog.bmp` | **493 × 312** | Большой фон слева на первом и последнем экране |
| `icon.ico` | **256 × 256** (лучше ещё 48, 32, 16 внутри ICO) | Ярлык и «Программы и компоненты» |
| `exclamation.ico` | **32 × 32** | Предупреждения |
| `info.ico` | **32 × 32** | Подсказки |
| `newfolder.ico` | **16 × 16** | Кнопка «новая папка» в обзоре |
| `upfolder.ico` | **16 × 16** | Кнопка «вверх» в обзоре |

Цвет фона заглушек — тёмный, акцент золотой. Можешь полностью перерисовать, имена файлов не меняй.
