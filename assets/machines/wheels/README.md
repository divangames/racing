# Спрайт колеса

`wheel-strip.svg` — единое колесо в 8 кадрах (32×24 px на кадр). Посадка колёс настраивается в лаборатории машин, не контрольными точками на спрайте.

В игре кадр выбирается по `r.wheelRot`, который накапливает пройденный путь. Поэтому стоящая машина не анимирует колёса, медленная машина вращает их медленно, а разгон автоматически ускоряет смену кадров. Размер и деформация задаются в раскладке машины в `rnr.html`.
