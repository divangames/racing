# Спрайт колеса

`wheel-strip.webp` — основной прозрачный спрайт-лист колеса в 8 больших кадрах (128×96 px на кадр). `wheel-strip.svg` остаётся запасным вариантом. В игре кадр всё равно рисуется в логическом размере 32×24 px до индивидуального масштабирования машины, поэтому игровые размеры колёс не меняются.

Посадка колёс настраивается в лаборатории машин, не контрольными точками на спрайте.

В игре кадр выбирается по `r.wheelRot`, который накапливает пройденный путь. Поэтому стоящая машина не анимирует колёса, медленная машина вращает их медленно, а разгон автоматически ускоряет смену кадров. Размер и деформация задаются в раскладке машины в `rnr.html`.
