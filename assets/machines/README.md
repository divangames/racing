# Машины — SVG-прототипы

Ресурсы для замены процедурной отрисовки в `drawCar()` (`rnr.html`).

## Структура

| Файл | Описание |
|------|----------|
| `car-chassis-prototype.svg` | Шаблон кузова с CSS-переменными и маркерами колёс |
| `wheel-prototype.svg` | Колесо 12×8 с протектором |
| `layout-reference.svg` | Карта координат (референс) |
| `cars/*.svg` | Кузова четырёх машин из `CARS[]` |

## Локальная система координат

- **Центр (0, 0)** — точка `translate(r.x, r.y)` и `rotate(r.ang)`
- **Ось +X** — направление «перед» машины
- **viewBox** кузова: `x ∈ [-32, 26]`, `y ∈ [-18, 18]` (с выхлопом и фарами)

### Точки крепления колёс

| Колесо | (x, y) | Поворот |
|--------|--------|---------|
| Заднее левое | -14, -14 | нет |
| Заднее правое | -14, 14 | нет |
| Переднее левое | 17, -14 | `r.wheelAngle` |
| Переднее правое | 17, 14 | `r.wheelAngle` |

Размер колеса в локальных координатах колеса: `rect(-6, -4, 12, 8)`.

### Слои кузова (порядок отрисовки)

1. Тень `ellipse(-2, 5, 26, 15)` — **не в SVG**, canvas
2. Ховер `ellipse(0, 7, 24, 11)` — только `car.hov`, canvas
3. Колёса — **отдельно**, поверх кузова
4. Нитро — динамически, canvas
5. Выхлоп `rect(-26, -10, 5, 20)` — `car.col2`
6. Корпус `rr(-23, -11, 46, 22, 6)` — `car.col`
7. Зад `rr(-23, -11, 13, 22, 5)` — `car.col2`
8. Полоса `rect(-19, -2, 36, 4)` — `ch.col`
9. Кабина `rr(3, -8, 11, 16, 3)` — `#0e1c28`
10. Фары `rect(20, ±8/3, 3, 5)` — `#ffe9a0`

## Цвета машин (из игры)

| idx | Машина | col | col2 |
|-----|--------|-----|------|
| 0 | Грязевой Дьявол | `#d24a22` | `#7e2a12` |
| 1 | V8 Перехватчик | `#2f7de0` | `#164a8c` |

## Интеграция в canvas

```javascript
// Предзагрузка (один раз)
const carSVG = await Promise.all(CARS.map((_, i) => loadImage(`assets/machines/cars/${names[i]}.svg`)));

// В drawCar — кузов из SVG, колёса процедурно
c.save();
c.translate(r.x, r.y);
c.rotate(r.ang);
c.scale(sc, sc);

// Тень и эффекты — как сейчас
c.fillStyle = 'rgba(0,0,0,.35)';
c.beginPath();
c.ellipse(-2, 5, 26, 15, 0, 0, TAU);
c.fill();

// Кузов (подгонка: viewBox -32..26 по X, -18..18 по Y → ~58×36)
c.drawImage(carSVG[r.car.idx], -29, -14, 58, 28);

// Колёса ПОВЕРХ кузова
if (!r.car.hov) {
  wd(-14, -14, 0);
  wd(-14, 14, 0);
  wd(17, -14, r.wheelAngle);
  wd(17, 14, r.wheelAngle);
}

if (r.nitro > 0) { /* пламя как в drawCar */ }

c.restore();
```

**Важно:** не включайте колёса в SVG кузова — передние колёса поворачиваются через `wheelAngle`.

## Просмотр

Откройте любой `.svg` в браузере или в Figma. Для шаблона с переменными цветов используйте `car-chassis-prototype.svg` и меняйте `--car-col`, `--car-col2`, `--ch-col` в `<style>`.
