# Фоны главного меню

Кадры подставляются по соотношению и плотности холста. Якорь `focusX` / `focusY` держит Медведя в кадре при `cover`.

Новый файл: `title-<персонаж>_ШИРИНАxВЫСОТА.webp` и строка в `titles.json`. Без записи в JSON кадр из имени всё равно подхватится, если движок уже знает папку — но якорь будет 0.5.

| Файл | Экран |
| --- | --- |
| `title-medved_1920x1080.webp` | 16:9 |
| `title-medved_3440x1440.webp` | ультраширокий 21:9 |
| `titles.json` | список, размеры, якорь |
