# Пролог «Чёрный Пояс»

Семь кадров после экрана «нажмите любую кнопку». Музыка — `assets/music/Load`.

Это лор арены, не сюжет Медведя. Сюжетный ролик — `assets/data/cats/campaign/` и пункт меню «Кампания».

## Кадры

1. Город после войны.  
2. Тоннели и ворота «Колесницы Войны».  
3. Смертельный заезд.  
4. Публика и рынок.  
5. Сетка и «личный» соперник.  
6. Ворота за спиной.  
7. Свет на решётке — старт.
