# Пролог «Чёрный Пояс»

Семь кадров после экрана «нажмите любую кнопку». Музыка — `assets/music/Load`.

Текст — атмосфера и интрига: город, арена, смертельный заезд, ощущение «тебя уже ждут». Без имён и спойлеров кампании.

Подсказка по кадрам: 1 город после войны, 2 тоннели и арена, 3 смертельный заезд, 4 публика и рынок, 5 сетка и «личный» соперник, 6 ворота и прожектора, 7 старт. Лица гонщиков в прологе не обязательны.

## Файлы

| Файл | Назначение |
| --- | --- |
| `lines.json` | Текст семи сцен |
| `01.webp` … `07.webp` | Кадры (можно `01.png` … `07.png` или `1.png` … `7.png`) |

Кадр на весь экран, тёмный комикс, лица из папок персонажей: `01` Медведь, `02` Ерш, `03` Бегемотик, `04` Башкир, `06` Янот. Не смешивать лица.

Рекомендуемый размер: **1920×1080** WebP.

Пока картинки нет, в игре будет номер кадра и текст.
