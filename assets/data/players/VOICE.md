# Голоса и реплики

Тексты лежат в папке гонщика: `NN/voice/lines.json`. Рядом — три пустых MP3 на каждую реплику. Записали голос — сохранили поверх файла с тем же именем.

## Папки

| Папка | Кто | `lines.json` |
|-------|-----|----------------|
| `01/voice/` | Медведь | игровой |
| `02/voice/` | Ерш | игровой |
| `03/voice/` | Бегемотик | игровой |
| `04/voice/` | Башкир | игровой |
| `05/voice/` | Борис Бык | NPC |
| `06/voice/` | Янот | игровой |
| `host/voice/` | Ведущий арены | NPC |

Ведущий не в `chars.js`: это голос толпы, не гонщик.

## Как назвать файл

`{событие}_{01|02|03}.mp3`

Пример: `assets/data/players/01/voice/start_02.mp3` — второй дубль старта Медведя.

События одни для всех:

| Код | Когда в игре |
|-----|----------------|
| `name` | Выбор гонщика / представление |
| `start` | Зелёный свет |
| `lead` | Вышел в лидеры |
| `chase` | Догоняет |
| `ram` | Таран |
| `hit` | Получил удар |
| `nitro` | Нитро |
| `kill` | Уничтожил соперника |
| `last_lap` | Последний круг |
| `win` | Победа |
| `lose` | Проигрыш |
| `taunt` | Рация / подкол |

Три файла на событие — три разных текста, не три одинаковых дубля. Игра потом возьмёт случайный.

## Запись

1. Открыть `NN/voice/СЧИТАТЬ.md` — таблица «файл / текст».
2. Читать только свою колонку. Чужие реплики не переписывать.
3. Коротко: одна-две секунды, без «эм» в начале.
4. Сохранить поверх пустого MP3. JSON не трогать, если не меняете текст.

Старые имена на выборе (`assets/voice/01_Player.mp3`) пока живут отдельно. Новые дубли имени — `NN/voice/name_01.mp3` и дальше.
