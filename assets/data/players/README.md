# Гонщики

Одна папка — один персонаж. Номер `NN` = индекс в `chars.js` плюс один.

```
assets/data/players/NN/
  NN_Player.webp          портрет
  NN_Player_fullbody.webp / _fullbody.webp  рост
  comics/                 кадры интро (1.png или 01.webp)
  NN_Имя.md               сюжет
  voice/                  реплики (lines.json) и MP3, по три дубля
```

Голоса: `VOICE.md`. Ведущий арены — `host/voice/`, не гонщик.

| Папка | Файл сюжета | Персонаж |
|-------|-------------|----------|
| `01` | `01_Medved.md` | МЕДВЕДЬ |
| `02` | `02_Ersh.md` | ЕРШ |
| `03` | `03_Begemotik.md` | БЕГЕМОТИК |
| `04` | `04_Bashkir.md` | БАШКИР |
| `05` | `05_Boris.md` | БОРИС БЫК (NPC) |
| `06` | `06_Yanot.md` | ЯНОТ |

Портрет: квадрат; в UI база 88×88 (на экране ×2). Рост: вертикальный кадр, ноги внизу; если файла нет — на витрине портрет.
