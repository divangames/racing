# Аватары гонщиков

Квадратные портреты и ростовые спрайты (WebP, запасной вариант — PNG). Порядок совпадает с `CHARS` в `rnr.html`.

| Файл | Рост | Персонаж |
|------|------|----------|
| `01_Player.webp` | `01_Player_fullbody.webp` | МЕДВЕДЬ |
| `02_Player.webp` | `02_Player_fullbody.webp` | ЕРШ |
| `03_Player.webp` | `03_Player_fullbody.webp` | БЕГЕМОТИК |
| `04_Player.webp` | `04_Player_fullbody.webp` | БАШКИР |
| `05_Player.webp` | `05_Player_fullbody.webp` | БОРИС БЫК |

Портрет: квадрат, в интерфейсе базовые 88×88 (на экране ×2).

Рост (`_fullbody`): вертикальный кадр с прозрачным фоном, ноги внизу. В тренажёрке и гараже — левая витрина. Пока файла нет, на витрине портрет.
