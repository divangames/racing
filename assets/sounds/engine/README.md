# Звук двигателя

Четыре рабочих клипа. Если у кузова нет папки `sound`, играет набор из `assets/sounds/engine/`. `sound_004.wav` в игре не используется.

| Файл | Когда |
|------|--------|
| `sound_001.wav` | Разовый набор скорости, не луп |
| `sound_002.wav` | Луп двигателя в движении после набора |
| `sound_003.wav` | Сброс газа и сразу в воздухе |
| `sound_005.wav` | Луп на месте |

На трамплине сразу `003`. На приземлении сразу `001`, затем луп `002` без паузы и без обрывка предыдущего лупа. Стык `002`/`005` бесшовный: тишина на краях клипа не зацикливается.

Путь у машины: `assets/data/cars/NN/sound/`.

Игрок — по центру на полной громкости. Соперники — те же клипы: ближе громче (потолок как у игрока), сторона — левый/правый канал.
