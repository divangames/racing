# Звук двигателя

Пять клипов. Если у кузова нет папки `sound`, играет набор из `assets/sounds/engine/`.

| Файл | Когда |
|------|--------|
| `sound_001.wav` | Разовый набор (рывок «передачи»), не луп |
| `sound_002.wav` | Луп полной скорости после набора |
| `sound_003.wav` | Сброс газа на ходу |
| `sound_004.wav` | Луп езды / накат |
| `sound_005.wav` | Луп на месте |

Путь у машины: `assets/data/cars/NN/sound/`.

Игрок — по центру на полной громкости. Соперники — те же клипы: ближе громче (потолок как у игрока), сторона — левый/правый канал.
